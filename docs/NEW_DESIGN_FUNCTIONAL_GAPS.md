# Deels — функциональные разрывы нового дизайна

Цель: сохранить визуальный эталон `Deels2024/deelsweb`, но поэтапно вернуть весь функционал существующего Laravel `Deels2024/deels`.

## Пакет 1 — Личный кабинет и социальные разделы — ГОТОВО

Возвращены в новый интерфейс через единый блок «Мои разделы»:
- мои челленджи;
- мои сторис;
- мои копилки;
- кошелёк;
- сообщения;
- мои лайки;
- друзья;
- подписки;
- подписчики;
- автоплатежи;
- благодарности / «Спасибо».

## Пакет 2 — Копилки — ГОТОВО

Публичная копилка:
- О сборе;
- Донатеры;
- Обновления;
- FAQ.

Управление своей копилкой:
- Основное;
- Награды;
- Обновления;
- FAQ.

Существующие донат, автоплатёж, лайк, follow, чат, share, health, сторис и платежные сценарии не заменяются.

## Пакет 3 — Челленджи и баттлы — СЛЕДУЮЩИЙ

Нужно явно вывести в новый UI функции, которые уже есть в Laravel:
- приглашения участников;
- принять / отклонить приглашение в баттл;
- join / leave / rejoin;
- reporting / отчётность;
- полезные сторис;
- выбор победителя создателем;
- журнал выполнения;
- battle reports;
- редактирование и остановка собственного челленджа/баттла;
- приватность и visibility;
- ритм и чек-ин.

## Пакет 4 — Кошелёк и платежи

Нужно сделать видимыми в новом UI:
- движения;
- billing;
- donate history;
- вывод средств и его ограничения;
- автоплатежи;
- статусы транзакций;
- App Store / coins состояния, где применимо.

## Пакет 5 — Профиль и социальный граф

Нужно довести до нового дизайна:
- реферальная программа;
- достоинства / титулы;
- место среди донатеров;
- процент от донатов;
- статистика приглашённых;
- followers / followings / friends;
- likes;
- публичный профиль;
- follow / message actions.

## Пакет 6 — Сообщения и уведомления

Нужно проверить и вывести:
- список диалогов;
- unread counters;
- системный диалог / уведомления;
- поиск по чатам;
- жалоба / блокировка;
- Firebase / WebSocket состояния;
- read status.

## Пакет 7 — Auth и безопасность

Нужно сохранить и визуально проверить:
- email verification code;
- phone verification;
- reset password;
- social auth;
- Telegram WebApp auth;
- captcha / anti-bot telemetry;
- honeypot;
- обязательные юридические согласия.

## Пакет 8 — Модерация и админка

Отдельно, не смешивая с пользовательским фасадом:
- stories moderation;
- challenge/battle moderation;
- campaign moderation;
- comments;
- users;
- games;
- tags;
- service balances;
- settings;
- newsletters / metrics / cron-инструменты.

## Правило миграции

1. Не менять бизнес-логику без необходимости.
2. Сначала переиспользовать существующий route/controller/service.
3. Новому дизайну давать доступ к функции через Blade/CSS/JS.
4. На каждый пакет добавлять smoke-check route contracts.
5. `main` и production не менять без отдельного разрешения.
